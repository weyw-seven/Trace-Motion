# 线稿到 TRJ2：周末开发计划

计划日期：2026-09-05。目标窗口：9 月 5 日至 9 月 6 日。

状态：R0 环境与回归基线、R1 图像预处理与坐标基线、R2 骨架与像素路径追踪、R3 LINE 端到端闭环完成；R4～R6 尚未实现。时间分配是估计，以阶段验收为准。

## 1. 本阶段交付目标

用户在本地界面打开一张干净线稿，设置绘图尺寸，生成中心线路径，检查绘图与空行程预览，导出当前固件目标支持的 TRJ2 文件及诊断报告。

本周末必须完成：PNG/JPEG 输入、中心线提取、Stroke 构建、毫米坐标变换、受误差约束的 LINE 简化、现有 Toolpath/TRJ2 后端接入、回读验证、命令行入口、轻量本地界面和回归测试。

可选增强：圆弧拟合、就近笔画排序与方向优化。两项不能阻塞上述完整交付。

不包含：原生 Bézier 固件执行、实车验收、真实笔机构、照片转线稿、灰度填充、自动恢复书写笔顺、复杂手动路径编辑、联网传输和安装包制作。

## 2. 固定协议与输出约定

- 保持 TRJ2/version 2、小端序、32 字节 Header、44 字节 Record。
- 文件长度严格为 32 + 44 × record_count；计数包含 Motion 与 Event。
- flags/reserved/未用 payload 为 0；不往保留字段添加界面或图像参数。
- 复用 traj2_format/validate/reader/writer 与双向 Toolpath 桥，不复制 struct 定义。
- 图像 Motion 允许当前固件可执行的 LINE 与 CIRCLE；图像导出流程禁止输出 CUBIC_BEZIER。
- 复用 PEN_UP/PEN_DOWN；WAIT 可选且显式配置，不用它代替机构动作完成判断。
- 初始逻辑笔状态 UP；每条独立 Stroke 前落笔、后抬笔；分离 Stroke 之间必须有抬笔空行程。
- Motion 起点隐式继承；事件不改变 logical XY；事件为零速屏障。
- start_yaw 为显式底盘朝向参数，不从路径切线推导。
- 默认将首笔起点平移到 WORLD (0,0)，Header 与第一条 Motion 起点一致，预览标示小车初始放置点。此默认不代表纸张左下角；图像至 WORLD 的变换写入报告。
- 输出尺寸默认按裁剪后的内容范围解释，保持比例；明确显示实际宽高，单轴退化图案按非零跨度定标。
- PC 连续性容差保持 0.01 mm。拟合误差、最短可执行段和实车精度是不同约束。
- 导出后必须回读实际 float32 数据，重新检查连续性、退化运动与目标类型支持。
- 保留 TRJ1 164 字节与 TRJ2 340 字节 Golden。

## 3. 架构与拟新增文件

文件名是实施建议，可按实际代码调整；保持现有公共接口兼容。

| 文件/目录 | 职责 |
|---|---|
| raster/config.py | 输入、尺寸、简化与输出配置；合法性验证 |
| raster/preprocess.py | 解码、透明背景合成、灰度、二值化、可配置去噪 |
| raster/skeleton.py | 骨架化、像素邻接与分叉区域处理 |
| raster/trace.py | 端点/分叉/闭环追踪；输出有序像素路径 |
| raster/coordinates.py | 像素到 WORLD 毫米的统一变换 |
| raster/simplify.py | 误差受限的折线简化，保留连接点与闭环 |
| raster/lineart.py | 单一转换服务，组装 Drawing，调用现有编译/导出桥 |
| target_validation.py | 当前固件类型、过短段、范围和量化后检查 |
| conversion_report.py | 配置、变换、统计、诊断与来源追溯 |
| cli.py | 无界面转换与验收入口 |
| ui/ | 本地界面；调用 pipeline，不实现第二套转换算法 |
| tests/fixtures/lineart/ | 小型合成图与固定代表样例 |

Pipeline 返回结构化结果：阶段图像、原始路径、Drawing、Toolpath、回读 Toolpath、TRJ2 bytes、诊断和统计。

先核对项目 .conda 环境及依赖，再选定图像处理和界面库并记录版本。界面优先采用 Python 本地浏览器方案，复用现有预览；避免引入独立前端构建链。

2026-09-05 完成记录：新增 `pc_trajectory/raster/` R1 模块和 56 项测试。`PreprocessConfig` 验证阈值、前景反转、连通组件过滤和图像尺寸上限；预处理应用 EXIF 方向、RGBA 到背景合成、灰度阈值与 8 连通组件过滤，不做断线连接。`PreprocessResult` 保存只读阶段数组、内容边界、组件统计、删除像素数与诊断，并能导出 source/grayscale/binary/cleaned PNG。`PixelWorldTransform` 使用像素中心跨度，保持统一比例、翻转 WORLD Y，并提供正变换、逆变换、WORLD bounds 与 JSON 友好描述。R1 测试包含透明/反色、PNG/JPEG/调色板、EXIF、噪点、随机连通组件 oracle、空白/单像素和尺寸异常。

### R2：骨架到 Stroke（约 3～4 小时，主要风险项）

建立邻接图并规范化分叉区域，避免对角邻接形成伪边/微小环。追踪端点间路径、分叉间路径及无端点闭环。用访问过的边记录覆盖，不能仅标记访问像素。闭环选取确定起点；分叉处先拆分笔画，不推断作者笔顺。

验收：直线、L、圆、T/Y/十字、分离路径都能重复得到相同结果；规范化图的有效边无意外遗漏或重复；被剔除毛刺、孤立点和分叉归并信息进入报告。

2026-09-05 完成记录：新增 `raster/skeleton.py`、`raster/trace.py` 和 `raster/trace_preview.py`。骨架化使用纯 NumPy Zhang-Suen 两阶段细化，不增加 OpenCV/scikit-image 依赖；图追踪使用 8 邻接并抑制有正交替代路径的对角捷径。相邻高阶像素合并为逻辑 Junction，按未访问无向边追踪开放路径和闭环，路径方向与闭环起点均确定化。结果提供节点、组件、原始/收缩/外部/已追踪边统计和诊断；可保存彩色路径、端点和分叉节点预览。R2 输出仍是 PixelPath，不构造毫米 Geometry 或 TRJ2。

R2 验收：初版新增测试 27 项。实际线稿验收发现 Zhang-Suen 删除条件误用了两个对角邻居：R1 主图保持 1 个组件，错误细化后却变成 7 个组件并出现竖线断点。已改为标准 P2/P4/P6/P8 条件，增加细化前后 8 连通组件数量不变的运行时诊断和粗交叉回归；该实图修复后保持 1 个组件且无错误诊断。随后处理了左上锐角产生的双路径小环：只检查同一对 degree-3 分叉之间恰好两条平行路径、且总周长不超过“估计笔画宽度 × 5”的情况，删除较长路线并重新追踪，使两个假分叉自动合并。独立闭环不受影响，该规则可用 `TraceConfig.suppress_small_parallel_loops=False` 关闭。最终实图为 3 条路径、外部边 3624/3624 全部追踪，产生一条显式 `SMALL_PARALLEL_LOOP_SUPPRESSED` warning。R2 专项 35 passed，完整回归 592 passed。预览改为自动缩放，避免约 1300×950 输入默认生成 10000 像素级 PNG。已知限制：对有宽度的线段，细化算法生成的是中轴拓扑，端帽可能比原始黑色区域短；R3 将在像素路径转毫米和简化阶段单独处理端点策略，不把这个现象隐式当作协议错误。

## 5. 界面要求

用户流程：导入图片 → 设置尺寸/提取参数 → 生成轨迹 → 检查预览/诊断 → 导出。

- 参数区：输出最大边长或宽/高约束（保持比例）、阈值、反色、噪点过滤、简化误差、绘图/空行程速度、加速度、固定 yaw。低频参数折叠。
- 预览区：原图、二值图/骨架、最终 WORLD 轨迹；支持缩放和移动，等比例毫米坐标。
- 最终轨迹区分绘图实线与空行程虚线，可开关方向、序号、起终点、需停车连接点。
- 统计区：实际尺寸、笔画数、记录数、绘图/空行程长度、文件大小和诊断。
- 导出：.traj、预览 PNG、JSON 报告；不默认显示未经执行器模型验证的精确运行时间。
- 进度状态、输入尺寸限制和重复点击处理保证界面可用；不增加多项目管理、云账户等功能。

## 6. 测试与最终完成定义

算法层验证拓扑、坐标、误差、闭环和确定性；协议层验证 canonical 格式、目标能力及 float32 回读；流程层验证每条 Motion 的笔状态与实际输出预览。

固定样例至少包含：水平/垂直/斜线、L、圆、椭圆、两条分离线、T/Y/十字、多闭环、噪点、断口、透明背景、非对称图形、空白和单点。短笔画不得被静默丢弃。

完成条件：

1. 既有回归全部通过，Golden 不变。
2. 规定样例集通过自动验收与人工预览检查。
3. GUI 与 CLI 使用相同服务，结果一致。
4. TRJ2 实际字节回读通过，输出中没有当前目标不支持的类型。
5. 参数、图像到 WORLD 变换、统计和警告可追溯。
6. 给出简单启动方式和至少一个端到端示例。
7. 交付标记为“PC 离线验收通过”；实机运动、机构时序和绘图精度仍待实验室验证。
