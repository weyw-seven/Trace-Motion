# 归档内容

本目录保存不参与当前发布构建的历史实验、阶段性记录和旧版示例，供追溯与参考。

- `firmware-legacy-experiments/`：不再由 `firmware/apps/` 构建的旧入口、实验代码和已被组件实现单元替代的注册文件。
- `development-notes/`：历史设计、交接与验收记录，可能反映当时的中间状态。
- `pc-legacy-examples/`：旧版 PC 脚本，不作为当前使用入口。

使用或公开归档材料前，请确认其版权来源、依赖许可和适用性。当前发布版本的构建与使用说明以根目录 README、`firmware/` 目录和 `docs/` 目录中的文档为准。
