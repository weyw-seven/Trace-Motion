# 归档说明

本目录保留整理前的历史材料，以便追溯和参考；它们不属于当前发布版的构建或运行路径。

- `firmware-legacy-experiments/`：旧的单文件测试入口、早期实现和已被替代的头文件。正式固件只从 `firmware/main/CMakeLists.txt` 列出的源文件构建。
- `development-notes/`：阶段性设计、验收和交接笔记。部分内容描述的是当时的计划或中间状态，阅读时应以根目录 README 和当前源代码为准。
- `pc-legacy-examples/`：无法在仓库任意位置直接运行的旧 PC 端手工脚本；保留其原貌以便查阅，不作为示例或测试入口。

归档内容应在确认版权来源后再公开；不能确认来源的文件不应推送到公开仓库。
