# 硬件验收测试

| 测试 | 目录 | 用途 | 运动风险 |
| --- | --- | --- | --- |
| 前馈标定 | `ff-calibration/` | 测量每个轮子正反方向的 PWM—轮速关系 | 原地旋转 |
| 启动阈值 | `startup-threshold/` | 测量各轮带载起转所需的原始 PWM | 单轮运动 |
| 小距离运动 | `small-motion/` | 检查短距离、横移、斜向和回退控制 | 底盘平移 |
| 里程计手推 | `odometry-push/` | 在电机关闭时检查编码器、IMU 与位姿融合 | 无主动运动 |
| MPU 监视 | `mpu-monitor/` | 检查姿态角、陀螺仪极性和静态噪声 | 无主动运动 |

所有主动运动测试均可能使底盘突然动作。刷写前抬起笔、清空周边区域，确认急停可用，并从低风险工况开始。测试完成后应刷回目标任务应用。
