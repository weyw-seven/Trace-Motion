# 固件应用

`apps/` 中每个目录都是独立的 ESP-IDF 工程根目录。请进入具体应用目录后运行 `idf.py`；不要在 `firmware/` 或 `apps/` 目录直接构建。

| 应用 | 定位 | 构建状态 |
| --- | --- | --- |
| `trajectory-drawing/` | 创新实验：接收 PC 端 TRJ2 轨迹并通过 N3 服务执行或模拟执行。 | 可构建；默认安全档。 |
| `line-infrared/` | 课程验收任务：四路红外循线、超声避障和 OLED 状态显示。 | 可构建；需实车标定。 |
| `line-ball-camera/` | 课程验收任务：UVC 相机循线、视觉找球与推球。 | 源码已整理；尚未提供可复现工程配置。 |

各应用的接线、参数和安全要求并不相同。构建或刷写前，请先阅读应用目录内的 README，并按 [硬件配置与标定指南](../../docs/HARDWARE_CALIBRATION.md) 完成对应检查。
